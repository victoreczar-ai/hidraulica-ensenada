✏️ Editar

Solo Admin puede editar las 4 tarjetas con el botón "Editar".

🛑 Stop

Cualquier usuario puede detener una tarea con el botón rojo STOP. Se registra quién detuvo, la fecha/hora, el motivo y opcionalmente a quién se sugiere contactar.

📄 PDF

Informe Gerente genera PDF profesional con todos los datos incluidos los STOP.

🔐 Roles

Admin: control total. Operador: solo carga datos. Ambos pueden usar STOP.

👥 Personal

Solo Admin puede gestionar categorías y personal desde el botón 👥. Se pueden crear, renombrar y eliminar categorías. Se pueden agregar, editar (nombre y categoría) y eliminar personas.
