📖 Instructivo de Uso

🚀 Inicio rápido

1. Clic en + Nueva Orden. 2. Complete Etapa 1: Ingreso.

🔧 Flujo

Etapas secuenciales: Ingreso → Operativa → Administración → Entrega. Si se detiene, usar derivación.

👥 Personal

Solo el Administrador puede gestionar personal y categorías.

📊 Informes

Exportar Excel genera informe completo.

🔄 Tiempo real

Los datos se sincronizan automáticamente entre todos los usuarios conectados.

🔐 Roles

Administrador: control total. Operador: carga datos pero no puede eliminar órdenes ni gestionar personal/categorías.
